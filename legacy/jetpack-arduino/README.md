# Legacy upstream Jetpack firmware

This directory contains Philip Sørensen's original, unmaintained Arduino
firmware as historical reference. It is not Jump Jet production firmware, is not
built by ESP-IDF, and must not be flashed as though it implements Jump Jet's
current safety architecture.

The sketch retains its original GPL-3.0 provenance and history. See
[`UPSTREAM.md`](../../UPSTREAM.md) for attribution, the original safety warning,
and links to the upstream/fork commits.
